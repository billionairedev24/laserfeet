Why Laser Feet

Simple to read. Built for the web.

Plain English

Keywords say what they do: when, otherwise, each, send. Types are worked out for you.

when age >= 18 { show "Adult" } otherwise { show "Minor" }

Objects and beams

Build with objects and rules, or with small functions called beams. Use whichever fits.

object User follows Greeter { name beam greet() { send "Hi, I am {name}" } }

Chain with then

Pass a result through steps like light through lenses.

users then keepIf(age >= 18) then sortBy(name)

Web built in

A real web server in a few lines. Lists and objects come back as JSON automatically.

use web server = web.open(8080) server.get("/hello") { send "Hello from Laser Feet" }

Tests built in

Write tests next to your code and run them with lf test.

test "adds up" { expect 2 + 2 is 4 }

Friendly problems

When something goes wrong, Laser Feet tells you where and suggests a fix.

Problem on line 3: I don't know what 'nmae' is. Did you mean 'name'?
Install

Run it on your computer

Laser Feet comes as one command, lf. Build it once from the source code, then run any .lf file.

You need Go 1.22 or newer to build lf today. People who run your finished apps won't need it once native builds arrive in version 0.2.

-- 1. inside the laserfeet folder, build the tool go build -o lf ./cmd/lf -- 2. run a program ./lf run examples/hello.lf -- 3. run the tests in a file ./lf test examples/shop_test.lf -- 4. start a web app on port 8080 ./lf run examples/web.lf

Learn Laser Feet

Ten short chapters. Every example has a Try it button that opens it in the playground.

Chapter 1Your first program

A program starts in its launch block. show prints a line. Notes start with -- and are ignored.

-- my first program launch { show "Hello, world" }

Save it as hello.lf and run lf run hello.lf. You can also leave out launch for quick scripts; the lines then run from top to bottom.

Chapter 2Values

Give a value a name with =. You don't write types; Laser Feet works them out. Use lock for a value that must never change. Put any value inside text with { }.

launch { name = "Ada" age = 36 lock speedOfLight = 299792 age = age + 1 show "{name} is {age}" show "Light: {speedOfLight} km/s" colors = ["red", "green"] colors.add("blue") show colors[0] show count(colors) city = {name: "Austin", state: "TX"} show city.name }

Chapter 3Beams

A beam is a function: inputs go in, and send shoots the result out. Inputs can be named when you call it.

beam add(a, b) { send a + b } beam factorial(n) { when n <= 1 { send 1 } send n * factorial(n - 1) } launch { show add(2, 3) show add(b: 10, a: 1) show factorial(5) double = x => x * 2 show double(21) }

x => x * 2 is a quick one-line beam, handy for passing to other beams.

Chapter 4Objects and rules

An object is a blueprint: it lists fields and the beams that work on them. Inside its beams, fields are used by name, and me means the object itself. A rule lists beams an object promises to have; follows makes the promise, and Laser Feet checks it.

rule Greeter { beam greet() } object User follows Greeter { name age visits = 0 beam greet() { send "Hi, I am {name}" } beam visit() { visits = visits + 1 } } launch { ada = User(name: "Ada", age: 36) ada.visit() show ada.greet() show "Visits: {ada.visits}" tobi = User("Tobi", 12) show tobi }

Make an object by calling its name. Fields can be filled in order or by name. Fields with a default, like visits = 0, can be left out.

Chapter 5Decisions and loops

when runs a block if the answer is yes. Chain more checks with otherwise when. Compare with is, is not, <, >, and combine with and, or, not.

launch { score = 72 when score >= 90 { show "A" } otherwise when score >= 70 { show "B" } otherwise { show "Keep going" } each n in 1 to 10 { when n % 2 is 0 { skip } when n > 7 { stop } show n } fuel = 3 loop while fuel > 0 { fuel = fuel - 1 } loop 2 times { show "Zap" } }

skip jumps to the next item and stop leaves the loop.

Chapter 6Chaining with then

then hands the result on the left to the beam on the right, as its first input. Inside keepIf, turn and sortBy, you can use the item's fields by name, or it for the item itself.

object User { name age } launch { users = [User("Ada", 36), User("Tobi", 12), User("Kemi", 25)] adults = users then keepIf(age >= 18) then sortBy(name) show adults then turn(name) then join(", ") show [4, 8, 15, 16, 23, 42] then keepIf(it > 10) then sum }

Chapter 7Handling problems

Wrap risky work in attempt. If anything fails, the fails block runs and receives the problem. Use fail to report a problem yourself.

beam divide(a, b) { when b is 0 { fail "can't divide {a} by zero" } send a / b } launch { attempt { show divide(10, 2) show divide(10, 0) } fails problem { show "Caught: {problem}" } show "Still running" }

Chapter 8Fast work

Put fast in front of work to run it at the same time as the rest of the program. The program waits for all fast work to finish before it ends.

beam brew(drink, seconds) { pause(seconds) show "{drink} is ready" } launch { fast brew("Tea", 0.4) fast brew("Coffee", 0.2) show "Ordered both" }

Chapter 9Web apps

use web brings in the web library. Add routes with server.get, server.post or server.on (any method), then start the server. Inside a route, request holds the details, and parts of the path written as :name arrive in request.params.

use web server = web.open(8080) server.get("/hello") { send "Hello from Laser Feet" } server.get("/square/:n") { n = number(request.params.n) send {number: n, square: n * n} } launch { show server.visit("/hello") show server.visit("/square/7") show server.visit("/missing").status fast server.start() }

What a route sends decides the reply: text is sent as text (or as a web page if it starts with <), lists, maps and objects become JSON, and web.status(404, "Not found") sends an error code. server.visit tries a route without a browser, which is useful in tests.

In the playground, start lists your routes instead of opening a port. On your computer, lf run app.lf serves real pages at http://localhost:8080.

Chapter 10Testing

A test block holds expect checks. lf test file.lf runs every test and reports which passed. In the playground, press Run tests.

beam discount(total) { when total >= 100 { send total * 0.9 } send total } test "big orders get 10 percent off" { expect discount(200) is 180 } test "small orders pay full price" { expect discount(50) is 50 }
